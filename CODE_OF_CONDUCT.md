# Code of Conduct

This project is for people learning and teaching the command line. We want it to
be welcoming to everyone, at every skill level.

## Our standards

- Be kind and patient. Everyone was a beginner once.
- Assume good faith, and give feedback on the work, not the person.
- Welcome questions. There are no "stupid" ones here.
- Respect different backgrounds, identities, experience levels and opinions.

Unacceptable behavior includes harassment, discrimination, personal attacks,
trolling, publishing others' private information, and anything that makes
participation unsafe or unpleasant for others.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that
do not follow this code, and may restrict participation by repeat offenders.

To report a problem, open a private security advisory on the repository or
contact the maintainer, Jermal Smith, through the contact details on
[github.com/jermsmit](https://github.com/jermsmit).

This code applies in all project spaces and when someone represents the project
in public.
